## Summary

AutoResearchClaw is an autonomous research-paper pipeline with a small local JSONL memory library, a separate run-local lesson store, and an optional bridge that turns lessons into reusable skills. The available source documents and code describe these paths, but this review found a constructor mismatch in the pipeline's experiment-memory initialization. No runtime behavior or benchmark result was verified.[[README](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/README.md)] [[MemoryStore](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/store.py)] [[pipeline runner](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/pipeline/runner.py)]

## Who and what

The public repository is maintained under the `aiming-lab` GitHub organization. Its README describes AutoResearchClaw as an open-source research pipeline that produces paper artifacts from a topic, with optional human guidance and integrations. Memory is a supporting subsystem in the repository; it is not a separately hosted memory service. The README also describes an optional MetaClaw integration for cross-run lesson-to-skill transfer.[[README](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/README.md)] [[integration guide](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/docs/integration-guide.md)]

## Architecture and data model

**Memory library.** `MemoryEntry` stores an ID, category (`ideation`, `experiment`, or `writing`), content, free-form metadata, an embedding vector, confidence, creation/access timestamps, and access count. `MemoryStore` holds entries in memory and persists one JSONL file per category. The default memory configuration names `.researchclaw/memory`, a 500-entry category cap, 90-day decay half-life, and confidence threshold 0.3; the pipeline runner also constructs a run-local `experiment_memory` directory for its experiment hook.[[MemoryStore](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/store.py)] [[configuration](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/config.py)] [[pipeline runner](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/pipeline/runner.py)]

**Run lessons and reusable skills.** Separately, `EvolutionStore` appends structured lesson records to `evolution/lessons.jsonl` under the current run directory. Lessons capture stage, category, severity, description, timestamp, and run ID. Prompt assembly reads lessons from that run directory and can also read up to five `arc-*` skill files under the configured MetaClaw skills directory. When the optional bridge is enabled, a post-run step can ask an LLM to convert sufficiently severe lessons into skill files. The default bridge configuration is disabled.[[evolution store](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/evolution.py)] [[prompt assembly](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/pipeline/_helpers.py)] [[bridge configuration](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/config.py)] [[integration guide](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/docs/integration-guide.md)]

## Write, update, delete, and retrieval

**Direct memory store.** `MemoryStore.add` accepts a valid category, content, optional metadata and embedding, and confidence. It generates a short UUID-derived ID, timestamps the item, and trims a category to its configured cap by retaining higher-confidence entries. `update_confidence` clamps score changes to [0, 1], while `mark_accessed` updates access time and count. `prune` removes entries below a confidence threshold or past a maximum age. Saving rewrites each category's full JSONL file; loading skips malformed lines. There is no content-edit or delete-by-ID API in the inspected store.[[MemoryStore](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/store.py)]

**Retrieval.** `MemoryRetriever` scores every selected entry using cosine similarity, exponential time decay, confidence, and normalized access count, then returns the top `k`. It can filter by category. Text recall requires a supplied embedding function; without one it logs a warning and returns an empty list. The embedding provider supports a configured OpenAI-compatible API, sentence-transformers when installed, and a hashed-token TF-IDF fallback. Prompt formatting also accepts a character limit.[[retriever](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/retriever.py)] [[embeddings](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/embeddings.py)] [[decay](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/decay.py)]

**Specialized wrappers and pipeline wiring.** Experiment, ideation, and writing wrappers build content and metadata for their categories and expose recall helpers. At the reviewed SHA, `ExperimentMemory.__init__` requires a `MemoryStore` and `MemoryRetriever`, while the pipeline runner calls it with `store_dir=`; that call is caught by a broad exception and initialization is skipped. The later experiment recording hook imports `ExperimentOutcome` and calls `record_outcome`, neither of which is defined in the inspected `experiment_memory.py`. The surrounding exception handler logs at debug level and skips recording. These are static source mismatches; this review did not execute them.[[experiment memory](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/experiment_memory.py)] [[pipeline runner](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/pipeline/runner.py)]

**Evolution write and recall.** The runner extracts lessons from completed stage results and run artifacts, then appends them to the run's JSONL file. Stage prompts can select recent/relevant lessons and prepend cross-run `arc-*` skill text. The lesson query is stage-oriented and recency/severity weighted; this path reads a run-local directory, so the source inspection alone does not establish that lessons persist across independent runs. The separate MetaClaw skill directory is the source-visible cross-run path when configured and enabled. The source does not expose a general update/delete interface for lessons; the JSONL lesson store appends and reads records.[[evolution store](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/evolution.py)] [[pipeline runner](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/pipeline/runner.py)] [[prompt assembly](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/pipeline/_helpers.py)] [[skill conversion](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/metaclaw_bridge/lesson_to_skill.py)]

## Scope isolation and provenance

The direct store groups by category and accepts caller-provided metadata such as run IDs, but the inspected record and retrieval model has no tenant, user, or enforced run-scope key. Callers can request category filtering; this is not principal isolation. The pipeline's evolution lessons are stored under the individual run directory, while skills are read from the configured shared MetaClaw path. These are different scopes and should not be treated as one enforced isolation boundary.[[MemoryStore](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/store.py)] [[evolution store](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/evolution.py)] [[prompt assembly](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/pipeline/_helpers.py)]

The direct memory entry carries timestamps, confidence, access counts, category, and optional application metadata. Lesson entries retain stage/severity/run identifiers, and generated skills contain LLM-authored guidance. These fields record context and ranking inputs, not a verified source passage or claim-to-evidence link. The inspected memory retrieval and prompt injection path does not independently validate evidence or adjudicate truth.[[MemoryStore](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/store.py)] [[evolution store](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/evolution.py)] [[skill conversion](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/metaclaw_bridge/lesson_to_skill.py)]

## Source-visible efficiency and observability

The direct store caps entries per category, uses local JSONL files, and scans in-memory entries linearly for ID lookup and retrieval scoring. Retrieval computes cosine and decay per candidate and sorts the scored results; there is no indexed nearest-neighbor structure in the inspected path. Embedding selection can involve a remote API, a local model, or a zero-dependency hashed-token fallback. The fallback bounds vector width at 256 dimensions, but no latency or quality comparison was measured.[[MemoryStore](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/store.py)] [[retriever](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/retriever.py)] [[embeddings](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/embeddings.py)]

Source-visible diagnostics include logging on persistence, malformed-entry skips, embedding fallback, pruning, and lesson export/conversion. Several integration exceptions are intentionally non-blocking and can leave memory features inactive while the wider pipeline continues. The MetaClaw bridge bounds generated skill count, and prompt assembly caps the number of injected learned skills at five. These are code limits and observability points, not measured reliability or cost results.[[MemoryStore](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/store.py)] [[embedding provider](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/embeddings.py)] [[prompt assembly](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/pipeline/_helpers.py)] [[skill conversion](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/metaclaw_bridge/lesson_to_skill.py)]

## Limits and unknowns

This bounded review inspected the current README and integration guide, direct memory store/retriever/embedding modules, specialized wrappers, pipeline runner and prompt assembly, evolution store, and lesson-to-skill bridge at the verified SHA. It did not inspect a deployed installation, persistent data, or runtime traces. Static call mismatches described above were not executed. The configuration includes a persistent memory directory, but the reviewed pipeline’s local experiment-memory setup is separate; wiring from configuration to all memory APIs was not established. Retrieval relevance, practical isolation, deletion completeness, and operational performance remain unknown beyond the source observations.[[configuration](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/config.py)] [[pipeline runner](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/pipeline/runner.py)] [[retriever](https://github.com/aiming-lab/AutoResearchClaw/blob/be4ba4755bf1b52220f25e13b2293b5956590070/researchclaw/memory/retriever.py)]
