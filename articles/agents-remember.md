## Architecture and data model

**Code and documentation observations.** The package contains the MCP server and dashboard; the Paseo host runs role agents. Settings map configured code repositories to separate memory repositories under a coordination root. The tool server resolves repository identity from that settings file, rejects repositories it does not list, and writes per-call logs under the coordination root or task enclosure.[[architecture](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/architecture.md)] [[README](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/README.md)]

The source of truth is a Git-versioned text tree in the memory repository. It includes Markdown cards mirrored under `onboarding/`, JSON sidecars for numbered references, code realizations and test proofs, route overviews, JSON knowledge records, and Curator judgment history. Record kinds include invariants, families, decisions, incidents, assumptions, limitations, failure modes, scenarios, diagnostics, terms, weaknesses, and dependents. Records have stable IDs, origins, status, and revisions; the JSON models and codecs validate records and verify revision payload digests when decoded.[[knowledge system](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/knowledge-system.md)] [[record codecs](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/memory/knowledge/records.py)]

The SQLite database is a derived index of a selected memory tree, not canonical storage. The inspected schema declares logical tables for repositories, invariants and revisions, families and revisions, family membership, source anchors, and realization claims. The index builder parses the text tree and records malformed or conflicting files as problems rather than guessing their contents.[[index schema](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/memory/knowledge/schema.py)] [[index builder](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/memory/knowledge_index/build.py)] [[knowledge system](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/knowledge-system.md)]

## Write, update, delete, and retrieval

**Write and update — source observations.** A Curator authors the meaning in a hand-off list. The shared knowledge writer fills mechanical fields such as IDs, source anchors, revisions, origin, and history-row bindings, then validates and plans or writes files. The MCP `knowledge_write` tool defaults to planning; with commit enabled it writes files but does not make the Git commit. Changed meaning increments a record revision, while Git preserves prior versions. Writer refusals and validation findings are reported; the writer is designed to roll back partial writes and report if rollback is incomplete or unverifiable.[[knowledge system](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/knowledge-system.md)] [[writer](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/application/knowledge_writer/writer.py)] [[authoring](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/application/knowledge_writer/authoring.py)] [[MCP knowledge handlers](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/mcp/tools/knowledge.py)]

**Delete.** The documentation says records are not physically deleted: a record leaves active use through `status: retired`. Validation requires records present in the comparison base to remain in the candidate tree. The checked paths establish logical retirement and Git history, not erasure of historical copies, backups, or external exports.[[knowledge system](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/knowledge-system.md)] [[authoring](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/application/knowledge_writer/authoring.py)]

**Retrieval.** `read_ar_files` names knowledge governing up to 20 requested code paths, including card locations, record counts and action-asking records; it returns locations rather than card text. `knowledge_read` selects a view of records (for example an invariant, family, record, weakness, or dependent), returns IDs, states and memory-file locations, and pages large selections with a continuation bound to the same snapshot and selection. Callers open the named files with their own file tools. Reads measure currentness against the selected code commit or working tree; they do not judge whether a claim is true.[[MCP tools reference](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/mcp-tools.md)] [[read path](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/application/knowledge_read.py)] [[MCP knowledge handlers](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/mcp/tools/knowledge.py)] [[path reader](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/application/read_files.py)]

## Scope isolation and provenance

**Scope isolation — source observation.** Settings choose the allowed repositories and their separate memory roots; task-scoped reads can use a task’s paired code and memory worktrees. This provides repository and task context selection in the inspected paths. It does not establish tenant authorization or protection when multiple users share the same host, filesystem, or tool-server credentials; no isolation probes or deployment review were performed.[[architecture](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/architecture.md)] [[MCP tools reference](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/mcp-tools.md)] [[MCP knowledge handlers](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/mcp/tools/knowledge.py)]

**Provenance and evidence.** Record origin ties authored material to a task or foundation wave, hand-off list, entry, and its evidence. File sidecars associate numbered citations with source targets and associate realizations and proofs with records; the Curator writes history rows that explain changes or a supported no-impact judgment. Code anchors record source identity/content and a locator, and read paths compare anchors against the requested code tree. These mechanisms make claims traceable and currentness inspectable; they do not independently establish that a recorded claim is correct or that a test proves every behavior a record states.[[knowledge system](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/knowledge-system.md)] [[authoring](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/application/knowledge_writer/authoring.py)] [[index builder](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/memory/knowledge_index/build.py)] [[MCP tools reference](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/mcp-tools.md)]

## Source-visible efficiency and observability

**Code/documentation observations, not measurements.** Reads are bounded by a maximum of 20 source paths for `read_ar_files`; knowledge views default to 32 items per page and can continue across a large result within a token threshold. The index builder caches parsed documents by SHA-256 during a process, so unchanged bytes can reuse parsed models; this is not a latency claim. The product logs MCP calls and exposes report locations, counts, refusals, integrity findings, and knowledge status/currentness. No latency, write-to-recall delay, token, cost, storage, or operational coverage measurement was collected for this review.[[MCP tools reference](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/mcp-tools.md)] [[index builder](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/mcp/src/agents_remember/memory/knowledge_index/build.py)] [[architecture](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/architecture.md)]

## Limits and unknowns

This is a bounded read-only inspection of the official README, architecture and knowledge-system documentation, plus selected current source paths at the verified SHA. I did not execute Agents Remember, its benchmarks, or tests.

Repository-scoped configuration and path selection are visible in source and docs; authenticated tenant isolation, deployment security, and concurrent multi-user behavior remain unverified. Retirement does not erase Git history or establish erasure from backups. Provenance and anchor checks provide traceability and code-currentness signals, not semantic truth. I did not review every tool, provider, role workflow, migration, or deployment configuration. Runtime retrieval quality and all metric outcomes remain unknown.[[architecture](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/architecture.md)] [[knowledge system](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/knowledge-system.md)] [[MCP tools reference](https://github.com/Foxfire1st/agents-remember/blob/f41e34b43195feafb98f011d18e6a9b746b76c34/docs/reference/mcp-tools.md)]
