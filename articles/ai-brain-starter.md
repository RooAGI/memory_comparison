## Architecture and data model

**Documentation observation.** The guide separates broad, every-session instructions in `CLAUDE.md` from narrower accumulated memories. Project memory lives under Claude Code's project-specific memory directory and consists of one Markdown file per memory plus an index named `MEMORY.md`. The index is loaded at session start up to its first 200 lines; individual files are selected and read on demand based on their descriptions.[[memory system guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/MEMORY_SYSTEM.md)]

The documented memory types are `user`, `feedback`, `project`, `reference`, and optional `discovery`. Files use YAML frontmatter with a title/name, relevance description, and type, followed by prose. Feedback and project memories may include a reason and application guidance. The guide recommends short index entries, descriptive filenames, and a hard cap of 50 entries; it also says memories should be backed by a durable vault or repository file rather than serve as the sole source of truth.[[memory system guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/MEMORY_SYSTEM.md)]

The repository describes a broader vault substrate: Markdown files are the source of truth; hooks apply deterministic checks around writes; and session lifecycle steps can file decisions, captures, and to-dos into distinct vault files. The close flow has a prompt hook that detects a closing signal and prepares paths/context, a model-written capture phase, then a Stop hook for fallback, aggregation, retention, and a targeted snapshot.[[README.md](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/README.md)] [[session-close guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/SESSION_CLOSE.md)] [[closing-signal hook](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/hooks/detect-closing-signal.py)] [[Stop-hook finalizer](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/scripts/session-end-hook.sh)]

## Write, update, delete, and retrieval

**Write/update — documentation and code observation.** The memory guide tells the agent to create or revise Markdown memory files and maintain `MEMORY.md`; it offers admission criteria such as avoiding ephemeral task state, duplicates of always-loaded instructions, and one-time fixes. It recommends pruning the oldest redundant item before adding a 51st entry and quarterly review of stale links and facts. The inspected hook source implements a different but related write path for session artifacts: the prompt hook pre-resolves a destination and prepares a session-file shell, after which the model writes captures using injected instructions. The Stop hook may backfill an empty session file and rebuild aggregate views.[[memory system guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/MEMORY_SYSTEM.md)] [[closing-signal hook](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/hooks/detect-closing-signal.py)] [[session-close guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/SESSION_CLOSE.md)] [[Stop-hook finalizer](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/scripts/session-end-hook.sh)]

No memory-specific API, database mutation endpoint, automatic supersession log, or tombstone model was found in the selected memory guide and close-hook sources. Updates and deletion of ordinary memory notes are file edits/removals governed by agent instructions and the user's filesystem; the guide documents pruning and quarterly cleanup but no versioned memory correction protocol. Session artifacts have a documented interactive undo script, but that is not a general memory delete API. These limits describe only the inspected sources.[[memory system guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/MEMORY_SYSTEM.md)] [[session-close guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/SESSION_CLOSE.md)]

Retrieval in the documented project-memory path is index-led: the short `MEMORY.md` is available at session start and the agent reads an individual note when its description matches the current work. The guide explicitly treats this as a convenience index, not canonical truth, and does not describe vector, keyword, or programmatic query over those files. Session start can also load vault context; the session-close detector resolves the nearest declared vault root and injects task-specific paths and instructions for the capture phase.[[memory system guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/MEMORY_SYSTEM.md)] [[closing-signal hook](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/hooks/detect-closing-signal.py)] [[session-close guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/SESSION_CLOSE.md)]

## Scope isolation and provenance

**Scope.** Local project memory is keyed by the Claude account and project path. The guide says it is not automatically visible to another account, tool, CI process, teammate, or retrieval runtime. It describes separate homes for local facts, team-shared principles, and model-general substrate guards. This is an information-routing model, not tenant authorization. The session-close resolver chooses the nearest folder declaring ownership, then falls back to configured `VAULT_ROOT` or the working directory; worktree paths are collapsed to the main vault root for session artifacts.[[memory system guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/MEMORY_SYSTEM.md)] [[closing-signal hook](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/hooks/detect-closing-signal.py)] [[session-close guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/SESSION_CLOSE.md)]

**Provenance/evidence.** A memory's type and descriptive frontmatter provide classification and retrieval cues. Feedback notes are directed to preserve the reason behind a rule; project notes are directed to include the reason alongside current state. The guide also says to back memory with a durable source file. These fields and practices do not provide a structured citation graph, claim-level source links, mutation audit, or measured support quality in the inspected memory model. The session close marker records metadata such as matched signal, timestamp, resolved paths, and message count, while session artifacts have frontmatter including a session identifier and worktree; these support operational attribution but are not evidence that every captured claim is correct.[[memory system guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/MEMORY_SYSTEM.md)] [[closing-signal hook](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/hooks/detect-closing-signal.py)] [[session-close guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/SESSION_CLOSE.md)]

## Source-visible efficiency and observability

**Code/documentation observations, not measurements.** The memory guide limits index loading to 200 lines, asks for index entries under roughly 150 characters, caps the collection at 50 entries, and recommends on-demand loading of individual notes. It explicitly frames memory as having a token cost at each session start. The close guide states a sub-500 ms budget for prompt-time preparation and describes a cheap no-marker Stop path plus a heavier close path; those are documented budgets/estimates, not results measured in this review.[[memory system guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/MEMORY_SYSTEM.md)] [[closing-signal hook](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/hooks/detect-closing-signal.py)] [[session-close guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/SESSION_CLOSE.md)]

The close hook logs errors to a local file, supports an opt-in debug trace, and can defer heavier aggregation/snapshot work under a load gate and mutex; the guide says deferred work is picked up by daily maintenance. The source exposes operational state and diagnostics, but the selected memory system does not expose retrieval latency, token/cost counters, or answer-quality measurements.[[session-close guide](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/docs/SESSION_CLOSE.md)] [[Stop-hook finalizer](https://github.com/mycelium-hq/ai-brain-starter/blob/6bdf33c8067725085de38a1d518354a832c48cfd/scripts/session-end-hook.sh)]
