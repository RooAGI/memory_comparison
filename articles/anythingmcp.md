## Summary

AnythingMCP is a self-hosted MCP gateway with an optional company knowledge layer. Its workspace memory stores short facts, preferences, and notes in personal or organization scope; MCP clients can search and save items, while people manage organization memory through a dashboard. The memory feature requires an Enterprise licence. This review covers the public source at the pinned revision, not the hosted service or runtime behavior.[[memory documentation](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/memory.md)] [[memory service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.service.ts)]

## Who and what

The repository and README identify AnythingMCP as an open-source, self-hosted gateway built by HelpCode.ai. The memory system is one feature of the larger gateway rather than a standalone memory library: it exposes memory tools on per-server MCP endpoints and a management API/dashboard, and connects memory facts to the workspace knowledge graph. The public docs state that workspace memory is an Enterprise feature.[[project README](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/README.md)] [[memory documentation](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/memory.md)]

## Architecture and data model

**Code observation.** The backend’s `MemoryService` uses Prisma and PostgreSQL. Each `MemoryItem` has organization, scope, optional personal owner, kind, text content, tags, status, JSON source metadata, optional normalized `about` entity and organization folder, creator and approver identifiers, approval time, and created/updated timestamps. A stored generated `tsvector` over content has a GIN index. Kinds are fact, preference, and note; scopes are personal and organization.[[memory service and types](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.service.ts)] [[MemoryItem schema](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/prisma/schema.prisma)] [[search-vector migration](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/prisma/migrations/20261019180000_workspace_memory/migration.sql)]

Company memory shares the knowledge-folder tree with AI skills. The documentation says folders may be limited by role and that folder visibility applies to memory search and knowledge-graph paths. The knowledge graph stores connector/entity/field names and relationships rather than observed business values; memory can attach facts to normalized entity names for `kg_how_to_obtain` to return where the caller may read them.[[memory documentation](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/memory.md)] [[knowledge graph documentation](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/knowledge-graph.md)] [[knowledge graph service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/knowledge-graph/kg.service.ts)]

## Write, update, delete, and retrieval

**Writes — code observation.** The MCP `memory_save` path writes a personal item for the caller or may propose an organization item when the caller has contribute access. Organization proposals default to `pending`; an administrator can configure automatic saving. Dashboard curators can write organization items active immediately. Writes normalize entity names and tags, reject content that matches credential or prompt-injection patterns, and store the input channel (`mcp` or `ui`), optional MCP server/client, and creator. Content is limited to 2,000 characters, tags to 10 of at most 40 characters each, and the code caps a member at 1,000 personal items per workspace and a workspace at 20,000 organization items. At most 200 organization proposals may wait for review.[[memory service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.service.ts)] [[memory MCP and dashboard routes](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.controller.ts)] [[memory docs: tools, approval, and limits](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/memory.md)]

**Update and review — code observation.** The dashboard supports editing a visible item. Administrators and editors can approve or reject pending organization items; approval changes status and records approver and time. The inspected code updates the item row in place and exposes no prior-content version history for memory items. The separate AI-skills feature has its own version behavior and is not the memory-item update model.[[memory service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.service.ts)] [[memory controller](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.controller.ts)] [[knowledge graph and skills docs](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/knowledge-graph.md)]

**Deletion — code observation.** The MCP forget tool deletes only the caller’s own personal item. Dashboard deletion is available to the personal owner or an organization curator. An administrator can erase a member’s personal memory for an organization; that path logs a security event with the affected count. The inspected service does not provide item tombstones or a general before/after mutation log. The documentation says account/workspace removal also deletes personal memory, and stored memory remains retained when the licence expires so administrators can still erase it.[[memory service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.service.ts)] [[memory documentation](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/memory.md)]

**Retrieval — code observation.** Search is limited to active rows in the caller’s organization and applies the requested scope, owner, folder visibility, and optional normalized entity filter. Empty search returns the most recently updated visible rows. Text search creates an any-word prefix query from up to 12 terms, ranks PostgreSQL full-text matches by `ts_rank`, and falls back to a case-insensitive substring match when full-text search returns no hits. Query input is truncated to 300 characters and result limits are clamped to 1–50 (default 10). The docs describe the PostgreSQL `simple` text configuration and no embedding requirement. The graph’s `kg_how_to_obtain` tool can also include matching active memory facts that the caller is allowed to see.[[memory service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.service.ts)] [[memory migration](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/prisma/migrations/20261019180000_workspace_memory/migration.sql)] [[memory documentation](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/memory.md)] [[knowledge graph service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/knowledge-graph/kg.service.ts)]

**Scope isolation — code observation.** Memory calls require an authenticated user identity and workspace membership with an enabled memory licence. Queries include the organization ID; personal reads additionally match the caller’s owner ID. Organization reads apply the member’s memory access level and visible-folder predicate; non-member/deactivated/no-user callers resolve to no memory access. The source contains these filters but this review did not test them against a running deployment.[[memory service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.service.ts)] [[memory controller](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.controller.ts)] [[memory documentation](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/memory.md)]

**Provenance and trust — code observation.** A memory row records its source channel, optional MCP server and client, creator, and (for approved organization items) approver and approval timestamp. The docs say organization items can be reviewed before activation and that returned memories are labeled as information written by people, not instructions. Credential-like strings and several instruction-override patterns are refused at write time. This metadata and filtering do not establish that the remembered statement is true or supported by a cited source passage.[[MemoryItem schema](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/prisma/schema.prisma)] [[memory service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.service.ts)] [[memory documentation](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/docs/memory.md)]

## Limits and unknowns

This is a bounded review of the current README, memory and knowledge-graph documentation, memory service/controller/schema, and search-index migration. It does not establish live behavior, answer quality, deployment security, complete physical erasure, backup retention, service latency, or performance under large workspaces. The feature is license-gated; personal and organization item caps apply. The inspected memory record has source metadata and approval state but no item revision history or evidence citation field. No implementation-level claim is made about every gateway subsystem or connector.[[project README](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/README.md)] [[memory service](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/src/memory/memory.service.ts)] [[MemoryItem schema](https://github.com/HelpCode-ai/anythingmcp/blob/e216684cb7b15a78bcba915dc400f91de12dfcb3/packages/backend/prisma/schema.prisma)]
