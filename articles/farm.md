FARM is a robotics scene-memory framework. Its README describes a ROS 2 mapping node and an offline dataset driver that use the same mapping pipeline, a Python retrieval library, command-line query tools, and a Viser 3D viewer. The project README identifies the paper and lists the repository's authors; this review concerns the public code and documentation, not the research team's internal deployment.[[README.md](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/README.md)]

## Architecture and data model

**Documentation observation.** FARM maps RGB-D frames into an object-level scene state. The README describes object records with 3D Gaussian geometry, captions, multi-modal embeddings, viewpoint evidence, and co-visibility relations. The public data model stores most per-object values in parallel tensors and lists, including means, packed covariance, appearance features, sparse voxel data, captions, embeddings, active/locked flags, and viewpoint-image references. `SceneState` snapshots are saved as `scene_state.pt`; image records can point to saved images or back to source frames. The README warns that PyTorch pickle scene-state files should only be opened when produced by FARM or another trusted source.[[README.md](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/README.md)] [[scene-state serialization](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/scene_state_io.py)] [[image record model](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/storage/models.py)]

**Code observation.** Offline and streaming callers share pure pipeline steps. Detections are transformed into world coordinates, matched against active map objects using feature and Gaussian-distribution similarity, then passed to in-place state updates. Those updates maintain Gaussian and voxel state, viewpoint image IDs, and co-visibility state; new objects can be queued for asynchronous captioning. The implementation also reports blocked merges and other update diagnostics.[[shared pipeline steps](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/pipeline/steps.py)] [[object state updates](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/map_update/object_update.py)]

## Write, update, delete, and retrieval

**Write and update — code observation.** Each RGB-D batch produces object detections and geometry. Correspondence matching uses appearance features and Hellinger distance between Gaussian estimates, then union-find resolves correspondences before state fusion. Matched detections update the existing object; unmatched detections can create rows. The state update retains sparse voxel evidence and viewpoint associations, while captioning and derived embeddings can be added asynchronously. These are implementation mechanisms, not measured object-identity or correction accuracy.[[README.md](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/README.md)] [[pipeline](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/pipeline/steps.py)] [[object updates](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/map_update/object_update.py)]

**Correction and delete — code observation.** Map fusion updates geometry and object features in place. The inspected lifecycle code soft-deactivates rows when they are merged or pruned; pruning selects active objects only when all configured criteria pass. The inspected sources did not establish a general permanent-delete operation or a correction-history model, and deactivated rows remain in the scene state. Whether a deactivated object can later reappear as a new row depends on future matching and was not tested.[[object updates](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/map_update/object_update.py)] [[pruning](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/map_update/pruning.py)]

**Retrieval — documentation and code observation.** The README describes text-to-object retrieval using caption text, raw query text, SigLIP2, and Qwen3-VL embedding channels, with reciprocal-rank fusion. For relational queries, the query is parsed into a target and spatial predicates, which are scored against candidate objects and anchors; an optional VLM reranker can reorder clusters. The retriever can emit candidate counts, component scores, selected viewpoint images, and debug outputs. These returned objects and scores do not by themselves prove a natural-language answer or establish calibrated abstention.[[README.md](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/README.md)] [[retriever](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/retrieval/scene_graph_retriever.py)] [[spatial query executor](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/retrieval/spatial_reasoning/executor.py)]

## Scope isolation, provenance, and evidence

**Scope observation.** The inspected state and retrieval paths operate on one loaded scene graph or scene-state file, and retrieval can narrow candidates by spatial relations or regions. The reviewed public sources did not show tenant, user, or project authorization boundaries. Spatial filtering is part of object retrieval; it is not evidence of access-control isolation. No cross-scene, cross-user, or cross-tenant probes were run.[[README.md](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/README.md)] [[retriever](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/retrieval/scene_graph_retriever.py)] [[spatial query executor](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/retrieval/spatial_reasoning/executor.py)]

**Provenance and visual evidence.** Each object can retain viewpoint image IDs. Image records include camera and pose metadata, an optional stored-image path, and a source-frame reference; retrieval can return a set of images that covers candidate objects. Detection-mask observations can retain packed mask evidence and crop references. This supports inspection of visual observations, but it is not a source-document citation or a claim-level evidence chain.[[scene graph processing](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/scene_graph.py)] [[image record model](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/storage/models.py)] [[scene-state serialization](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/scene_state_io.py)] [[mask observations](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/map_update/mask_observations.py)]

## Efficiency and observability

**Source-visible design.** FARM stores compact per-object geometry and appearance features instead of retaining every full image as the primary memory item; image persistence is optional and source references can resolve images from source datasets. Matching and retrieval use candidate selection, multi-channel rank fusion, vectorized geometry/predicate scoring, and bounded candidate sets. The retriever can log query and candidate counts, expose component scores, and persist debug outputs. Pipeline code also returns counts for blocked merges and voxel updates. These are source observations, not measured efficiency or reliability.[[README.md](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/README.md)] [[image records](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/storage/models.py)] [[retriever](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/retrieval/scene_graph_retriever.py)] [[object update diagnostics](https://github.com/GoldenGait/FARM-Project/blob/2fcaf8602e741341a70ca980133f7ff05cfc83a2/src/scene_graph/map_update/object_update.py)]
