agent-afk is a locally run TypeScript coding-agent framework. Its README describes cross-session memory as local-only state under `~/.afk/state/memory/`, shared by its REPL, chat, daemon, and Telegram surfaces. This review covers the repository's memory implementation at the pinned revision; README product statements are attributed as documentation, not runtime measurements.[[README.md — memory and state overview](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/README.md)] [[src/agent/README.md — module map](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/README.md)]

## Architecture and data model

**Code observation.** `MemoryStore` composes a SQLite database (`memory.db`) for session records and facts, a flat `HOT.md` prompt-memory file with a one-version backup, a `procedures/` directory of Markdown procedures, and a separate SQLite FTS sidecar for session facets. The facts table stores category, content, creation time, session ID, source surface, supersession pointer, confidence, access count, last-access time, and nullable evidence. Schema version 6 includes an FTS5 virtual table for fact content/category and a unique fact fingerprint.[[memory-store.ts — MemoryStore and persistence files](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.ts)] [[memory-store.schema.ts — facts/session schema and FTS triggers](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.schema.ts)] [[facet-fts-store.ts — facet index sidecar](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/facet-fts-store.ts)]

The README describes two tiers: a small hot file inserted into future system prompts and an unbounded FTS-searchable archive loaded on demand. Source code caps hot memory at 5,250 characters (a rough 1,500-token estimate), preserves an initial identity region when truncating, appends a truncation marker, saves atomically, and keeps a prior-file backup. The loader injects hot memory before session construction; source code comments explain that the provider prompt is assembled at construction time.[[README.md — hot memory and fact archive](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/README.md)] [[memory-store.ts — saveHot and hotUsage](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.ts)] [[memory-loader.ts — prompt injection and episode recall](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-loader.ts)]

## Write, update, delete, and retrieval

**Code observation — writes.** `memory_update` accepts `target: hot|fact` and `action: set|supersede|remove`. Fact writes append a JSONL WAL entry before inserting into SQLite. The WAL is replayed on a later open if SQLite is behind. Hot writes use the capped atomic file path described above. `procedure_write` writes or overwrites a named Markdown file with name, creation time, source session, and access-count frontmatter. A session-end hook records completed top-level sessions; subagent sessions are excluded according to the README/module description.[[memory-tools.ts — tool schemas and handlers](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-tools.ts)] [[memory-store.ts — storeFact, saveHot, and WAL-backed persistence](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.ts)] [[memory-store.wal.ts — append and replay](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.wal.ts)] [[memory-store.procedures.ts — procedure files](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.procedures.ts)] [[memory-hooks.ts — session hooks](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-hooks.ts)]

**Code observation — correction and deletion.** Fact `supersede` inserts a replacement row, carries the old session/source, retains prior evidence unless the caller replaces or explicitly clears it, and points the old row at the replacement. Search excludes rows with a supersession pointer. Fact `remove` issues a hard SQL delete by ID; the FTS delete trigger removes its indexed row. The repository also contains an opt-in, soft-delete garbage-collection sweep for eligible never-accessed facts; those rows remain in SQLite and are hidden by the same active-row filter. The inspected paths do not establish a single erase operation across facts, hot memory, procedure files, session records, facet caches, backups, and all other persisted state.[[memory-store.facts.ts — supersedeFact](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.facts.ts)] [[memory-store.ts — removeFact and active-row search](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.ts)] [[memory-store.schema.ts — FTS delete trigger](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.schema.ts)] [[memory-gc-sweep.ts — opt-in soft deletion](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-gc-sweep.ts)]

**Code observation — retrieval.** `memory_search` searches facts with SQLite FTS5, optionally filters category and creation date, excludes superseded rows, orders by FTS rank, and defaults to ten results. The query sanitizer retries certain punctuation-containing bare terms while preserving quoted phrases, boolean operators, and prefix wildcards. Procedure search scans the Markdown files for any query term. Hot memory is injected at session start rather than searched. Episode recall is separately opt-in, caps prompt insertion at three episodes and a 6,000-token estimate, and includes a dry-run mode; these are implementation controls, not evidence of recall quality.[[memory-tools.ts — memory_search interface](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-tools.ts)] [[memory-store.ts — searchFacts and combined search](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.ts)] [[memory-store.fts.ts — FTS query handling](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.fts.ts)] [[memory-store.procedures.ts — procedure search](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.procedures.ts)] [[memory-loader.ts — episode recall controls](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-loader.ts)]

## Scope isolation and provenance

**Code observation.** The README places this state under the local user's `~/.afk` tree and says the four interaction surfaces share the store. Fact rows carry session and source-surface metadata, but the inspected fact schema/search API has no user, tenant, or project scope key. Local filesystem ownership and this layout are not proof of application-level authorization or cross-user isolation. Episode recall uses the invocation's working directory as context, but that does not establish a general archive scope boundary.[[README.md — local state and shared surfaces](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/README.md)] [[memory-store.schema.ts — fact fields](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.schema.ts)] [[memory-loader.ts — cwd-dependent episode recall](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-loader.ts)]

The evidence gate treats `convention` as a checkable codebase claim category. With the gate enabled (default), missing evidence does not reject a write; the code returns it as `[unverified]`. Learning facts receive an `[auto-reflected]` marker at recall, while preferences and decisions are not gated. Evidence is stored as a plain citation string such as file/line, commit SHA, or trace event ID. This is provenance metadata, not a verifier that the reference resolves or supports the claim.[[memory-evidence.ts — categories and recall tags](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-evidence.ts)] [[memory-tools.ts — evidence warning and result handling](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-tools.ts)] [[memory-store.schema.ts — evidence column](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.schema.ts)]

## Source-visible efficiency and observability

**Code observation.** The fact archive uses an FTS5 content index with insert/update/delete triggers, a rank-ordered query with a row limit, schema versioning, and a JSONL WAL for fact writes. SQLite connections configure a 5-second busy timeout. Search increments access counters in a single bulk update and treats an access-accounting failure as non-fatal. Procedure lookup scans procedure files and performs substring checks per query term. These are visible implementation choices; no latency or scale claim follows from them.[[memory-store.schema.ts — FTS5 index and triggers](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.schema.ts)] [[memory-store.ts — WAL, connection, and access accounting](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.ts)] [[memory-store.procedures.ts — linear procedure scan](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.procedures.ts)]

The schema exposes session token/cost fields; facts expose access count and last-access time; hot-memory usage reports estimated tokens and cap utilization. The inspected memory path does not establish a measured retrieval-latency distribution, write-to-recall delay, or storage-bytes reporting. README telemetry statements describe local operation; no runtime telemetry was collected for this review.[[memory-store.schema.ts — session and fact fields](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.schema.ts)] [[memory-store.ts — hot usage report](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.ts)] [[README.md — telemetry and local-only statement](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/README.md)]

## Limits and unknowns

This review is a bounded, read-only inspection of the README and selected memory modules at the verified SHA. It did not execute agent-afk, inspect every call site, validate authorization behavior, probe data recovery, or test deletion across all persistence surfaces. Unknown means unverified here, not a claim that the behavior is absent. The memory archive shares a local state root across surfaces; deployment arrangements that change local accounts or state paths were not assessed.[[README.md](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/README.md)] [[memory-store.ts](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-store.ts)] [[memory-tools.ts](https://github.com/griffinwork40/agent-afk/blob/d577927d0033d4779bffc003de408053b06e7279/src/agent/memory/memory-tools.ts)]
