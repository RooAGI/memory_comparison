## Architecture and data model

The implementation is concentrated in agent.py: it builds an ADK orchestrator with ingest, consolidation, and query specialist agents; persists records in a local SQLite database; polls an inbox; runs a periodic consolidation coroutine; and exposes an aiohttp API. The separate Streamlit dashboard calls the local API.[[agent implementation](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[dashboard](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/dashboard.py)]

SQLite creates three tables. memories stores a numeric ID, source string, raw text, summary, JSON-encoded entities/topics/connections, importance, UTC creation time, and a consolidated flag. consolidations stores source IDs, a summary, an insight, and timestamp. processed_files records inbox paths and processing times. The code does not declare foreign keys or a user, tenant, project, or agent scope column.[[SQLite schema and store](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)]

The IngestAgent asks Gemini to describe input, summarize it, extract entities and topics, assign importance, then call store_memory. The QueryAgent is instructed to read stored memories and consolidation history, answer only from those results, and cite numeric memory IDs. The ConsolidateAgent is instructed to find patterns and write connections, a synthesis, and an insight.[[agent definitions and prompts](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)]

## Write, update, delete, and retrieval

**Write and file ingestion.** The HTTP ingest endpoint accepts text and a source label; the folder poller accepts the listed text and media extensions. Text files are read as UTF-8 with replacement and truncated to 10,000 characters. Supported media is sent as multimodal bytes, but files larger than 20 MiB are skipped. Store inserts a new row with the original text, generated summary, entities, topics, importance, and source. The inspected code has no deduplication or general memory-update operation.[[ingest and store](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[file watcher and media limit](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[HTTP ingest route](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)]

**Consolidation.** The timer waits the configured interval (default 30 minutes), counts unconsolidated memories, and calls the specialist when there are at least two. The reader supplies at most the ten newest unconsolidated records. Store writes a new consolidation, appends connection objects to referenced memory rows, and marks the supplied IDs consolidated. The code does not verify that the model's source IDs belong to the batch it read; scheduled and manual consolidation share this path.[[consolidation read/write](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[periodic loop](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)]

**Delete.** The API can delete one memory by ID or clear the database's memories, consolidations, and processed-file markers. Clear also removes non-hidden inbox files under the configured watcher path. No tombstone, revision history, or deletion audit is stored by these paths; erasure from external provider logs, backups, or other copies is not established.[[delete and clear](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[HTTP delete and clear routes](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)]

**Retrieval.** Despite the QueryAgent's broad wording, read_all_memories returns only the 50 newest memory rows; consolidation history returns only the 10 newest records. No query-specific keyword or vector ranking is implemented in these read functions. The model receives those bounded tool results and is prompted to synthesize an answer with memory-ID references. Whether it reliably abstains or cites supporting rows was not evaluated.[[memory readers](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[query prompt](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)]

## Scope isolation and provenance

There is no tenant or user key in the schema. Each ADK request creates an in-memory session with the fixed user ID agent, while the HTTP server binds to 0.0.0.0 and the inspected handlers show no authentication or authorization layer. This is source-visible absence in the reviewed files, not a deployment-wide security assessment; the sample should not be treated as providing caller isolation.[[schema and ADK session setup](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[session and server setup](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[HTTP routes and bind address](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)]

Provenance consists mainly of a source label, retained raw input, creation timestamp, and numeric memory IDs. Consolidation rows keep the model-supplied source ID list, summary, and insight; generated connections carry endpoint IDs and a relationship label. Query instructions ask the model to cite memory IDs, but no source spans, claim-to-evidence links, confidence calibration, or provenance validation is implemented in the inspected path.[[record schema](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[write and consolidation](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[query prompt](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)]

## Source-visible efficiency and observability

The design avoids a vector database and embedding step, but sends ingest, consolidation, and query work to Gemini. Folder scanning polls every five seconds by default; text input is capped at 10,000 characters, media at 20 MiB, consolidation batches at 10 records, and reads at 50 memories plus 10 consolidations. Those are code limits, not performance measurements.[[README architecture](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/README.md)] [[watcher and limits](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[read and consolidate bounds](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)]

The app logs stored summaries, deletes, file errors, timer activity, and database counts. The /status endpoint reports total memories, unconsolidated memories, and consolidation count. Dashboard actions display request elapsed time using a local wall clock. The inspected paths do not expose token counts, provider billing, storage bytes, retrieval latency distributions, or a durable operation trace.[[logging and status](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[status counters](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/agent.py)] [[dashboard timing](https://github.com/GoogleCloudPlatform/generative-ai/blob/d86c5cbb6d2401960509e1a15827afb1bb9a438a/gemini/agents/always-on-memory-agent/dashboard.py)]
